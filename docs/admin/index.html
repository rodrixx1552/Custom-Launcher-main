Administra el modpack desde aquí.

Inicia sesión con un token de GitHub de alcance limitado. El token se conserva solo en la memoria de esta pestaña y se comprueba que pertenezca a rodrixx1552.

¿Cómo crear el token?
  1. En GitHub, abre Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Limita el acceso al repositorio Custom-Launcher-main.
  3. Da permisos de repositorio Contents: Read and write y Actions: Read and write. Añade una caducidad.
  4. Copia el token aquí. Nunca lo envíes por chat ni lo guardes en el código.
